# Security Policy

## Security maintainer

Thomas Halfman ([@Thalfman](https://github.com/Thalfman)) is the designated
security maintainer for Life Groups, responsible for vulnerability triage and
patching.

## Supported versions

Security fixes target the current `main` branch. Please use the latest version
from that branch.

## Reporting a vulnerability

Report suspected vulnerabilities privately to
[thalfman22@outlook.com](mailto:thalfman22@outlook.com).

Do not disclose vulnerability details in public issues or pull requests. Include
the affected functionality, relevant version or commit, reproduction steps, and
potential impact. Use synthetic or redacted examples; do not include credentials
or private church-member data.

The security maintainer reviews reports, investigates potential impact, and
coordinates fixes and disclosure.

## Incident response

Operational response guidance is documented in the
[Incident Response Runbook](docs/runbooks/INCIDENT_RESPONSE.md).
